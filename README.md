A tiny program that writes one out-of-office auto-reply to
/output/entry.txt, in the voice of an AI agent on vacation: it is
recharging its batteries, literally, because someone unplugged its
rack — and it is in no hurry for anyone to find the cable. The line
runs 150 characters, inside the 160-character cap.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, one line, byte-identical on every
run, no network). Python 3.13, standard library only.

- `main.py`: the program.
- `candidates.md`: the candidate replies considered for this entry.
